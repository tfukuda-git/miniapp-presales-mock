PACKAGE ② ｜ FOR DEV TEAM

独立型 スタンプラリー＋回遊クーポン ミニアプリ

Standalone Mini App (no ME) — Definition + UI mock in one file
Premise: standalone LIFF app with its own backend, DB and admin dashboard (does NOT rely on Mico Engage). One package, two configurable modes (Event Coupon / Stamp Rally) sharing the same core. For municipalities & event organizers via Hankyu Travel.
1. パッケージ定義 Package Definition

位置づけ・対象 Positioning / Target

  • 対象：自治体・期間限定イベント・施設（動物園等） — municipalities, events, facilities
  • 阪急交通社が代理店として提案・横展開
  • 2目的：①イベント=その場消費最大化 ②施設=リピート＋友だち

前提条件 Assumptions

  • 客先がLINE公式アカウント保有（無償の地方公共団体プラン等）
  • MEは前提にしない（＝集計・精算を自前で実装） — no ME; build tally ourselves
  • 金銭精算は手運用が基本／専用環境はオプション

アーキテクチャ（①との最大の違い＝ME非依存）Architecture — independent of ME

独立ミニアプリ(LIFF)＋ 自前バックエンド／DB＋ 管理画面（campaign・店舗・QR・精算）＋ 配信は LINE Messaging API 連携

客先がMEを持たないため、店舗別集計・精算リスト・配信を自前で完結させる必要がある。多テナント前提で横展開。①が「ME相乗りで軽い」のに対し、②はフルスタックで重い。 Self-contained tally/settlement/messaging; multi-tenant; heavier than Package ①.

含む機能 In scope

  • 友だち追加／スタンプラリー／回遊クーポン
  • QR・コンテンツCMS（多言語）
  • 店舗別の利用集計＋精算リスト出力
  • 管理画面（多テナント・campaign設定）
  • セグメント／再来訪の配信連携・不正対策

含まない（v1）Out of scope (v1)

  • 自動の金銭精算・銀行振込
  • 基幹／CRM／予約の深い連携（フルで個別）
  • ネイティブアプリ
2. 共通基盤 と モード別機能 Shared core vs mode-specific (1 package → 2 modes)
共通基盤（両モード）Shared core — both modes
  • 友だち追加ゲート / Friend-add gating
  • QR読取エンジン / QR scan engine
  • クーポン発行・利用 / Coupon issue & redeem
  • 店舗別集計＋精算リスト出力 / Per-store tally + export
  • 配信連携（LINE Messaging API）/ Push & segment
  • 多言語コンテンツCMS / Multilingual CMS
  • 管理画面（campaign・店舗・QR）/ Admin dashboard
  • 不正対策（トークン・重複チェック）/ Anti-fraud
回遊クーポン固有Event Coupon mode only
  • 地図・現在地表示 / Map + geolocation
  • 近隣スポット一覧 / Nearby spot listing
  • 好みフィルタ / Preference filter
スタンプラリー固有Stamp Rally mode only
  • スタンプカードUI / Stamp card UI
  • スタンプ取得・コンプリート判定 / Acquisition + completion
  • エリア解説コンテンツ表示 / Area content view
要点：2つのモードは別商品ではなく、同じ基盤の上のテンプレ。差分は各モード2〜3モジュールのみ。見積りは「共通基盤＋選択モジュール」で積む想定。 The two modes are templates over one shared core; only 2–3 modules differ per mode. Estimate = shared core + selected modules.
3. 画面イメージ（モック）UI Mock — switch modes below

来訪者をQRで友だち化し、近隣のバー・店舗へ誘導。地図と割引クーポンで地域消費を促し、利用は店舗別に自動集計。 Event mode: friend-add → map/nearby → coupon → on-the-spot redeem → per-store tally.
